# Modular CV Generator - SuperCollider
A SuperCollider-based modular control voltage (CV) generator featuring 8 independent instances and 16 selectable signal generator algorithms: SinOsc, LFSaw, LatoocarfianC, Gendy3, HenonC, LFNoise0, LFNoise1, LFNoise2, Dust, Crackle, LorenzL, GbmanL, StandardL, CuspL, FBSineC, and LinCongC. Each instance provides independent generator selection, output routing across 16 output buses, frequency control (0–15 Hz), amplitude adjustment (0–1), and on/off switching. Designed for multichannel hardware setups and experimental control signal generation.
